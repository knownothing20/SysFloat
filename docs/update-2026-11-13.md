# 2026-11-13 界面更新

本次更新说明对应当前源码。可下载附件及版本请查看 [Releases](https://github.com/knownothing20/SysFloat/releases)。

## 贴边窄条

- 窄条分为 CPU、内存、显存三个等长区域，横向从左到右、竖向从上到下排列。
- 主区域之间使用宽间隔和亮色分隔线，双显卡之间使用较细的分隔线。
- 进度采用固定蓝、紫、绿，亮色长度表示占用比例。两张显卡分别显示各自的进度。
- 未占用部分采用完整悬浮框的背景色和透明度，低占用与零占用时可通过分隔线识别区域位置。
- 收起时随现有采样刷新窄条，展开时由完整面板显示资源数据和时钟。

![分段窄条示例](images/sliver-edge.png)

示例数据为 CPU 20%、内存 43%、双显卡 5% 与 75%，以 75% 背景叠在白色示例桌面上展示。

## 停靠外形

- 停靠、自动滑入和自动滑出期间，靠屏幕侧的两个角保持直角，外侧两个角保留圆角。
- 手动拖离屏幕边缘时恢复四个圆角，窗口绘制和原生窗口区域同步更新。

![顶部停靠的完整面板](images/top-docked.png)

## 面板与提醒

- 四种布局的数字和进度条统一采用指标固定颜色，面板内进度条使用深色轨道。
- CPU、内存与每张显卡的持续超限计时继续用于托盘提醒及可选通知。
- 四种布局的示例截图已更新，使用当前绘制代码和示例数据生成。
- 修正展开版排行标题的数量占位符，标题显示当前应用数量。

![横版双显卡示例](images/horizontal.png)
