# SysFloat v1.0.1

## 界面改进

- 收窄竖版窗口，减少两侧留白。
- 修正展开版太平洋时钟的对齐。
- 展开版默认显示内存排行；点击左侧 CPU、RAM 或 VRAM，右侧切换对应进程 Top 5。
- 选中指标和右侧排行使用相同颜色及连贯的面板样式。
- 保留窗口拖动、位置锁定、悬停详情与省资源采样。

## 采集

- CPU 使用真实进程 CPU 时间差值，按逻辑处理器数量归一；首次选择时短暂等待采样。
- 内存使用进程工作集。
- 显存使用 Windows 专用 GPU 内存计数器，按 PID 汇总各 GPU；取不到数据时明确显示不可用。
- 仅展开版可见时采集当前选择的排行，关闭或隐藏时释放采集资源。

## 使用

下载 `SysFloat.exe`，适用于 64 位 Windows，不需要安装 .NET。校验值见 `SysFloat.exe.sha256`。

显存排行是系统计数器口径，与左侧硬件传感器数据并不完全相同；请勿将各进程显存简单相加视为总体占用。

## 验证

88 项检查通过，包含真实 CPU/显存进程数据、点击切换、锁定与拖动、采集句柄释放和 100%/150%/200% DPI 渲染。
