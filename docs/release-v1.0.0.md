# SysFloat v1.0.0

方便查看系统资源，也方便使用 Codex 和 Claude 时参考美国太平洋时间。

## 功能

- CPU、物理内存、显存实时占用。
- 横版、竖版、展开版，统一深色样式。
- 美国太平洋时钟，自动切换 PST/PDT 并显示日期。
- 鼠标悬停查看详细资源数据。
- 可配置高占用阈值、持续时间和可选托盘通知。
- 省资源模式支持 1、3、5 秒采样，进程排行仅在展开版可见时刷新。
- 重做监控设置窗口，适配高 DPI。
- 修正显存 MB/GB 换算和进程对象释放。

## 下载

下载附件 `SysFloat.exe`，适用于 64 位 Windows，不需要安装 .NET。约 146 MB，包含运行时。

附件 `SysFloat.exe.sha256` 可用于校验。PowerShell 中执行 `Get-FileHash .\SysFloat.exe -Algorithm SHA256`，结果应与校验文件一致。

程序未签名；当前内置运行时为 .NET 5，已结束官方支持。

68 项检查通过，覆盖时区、持续提醒、设置操作、采样间隔、真实托盘接线和 100%/150%/200% DPI 渲染。发布成品已在禁用系统 .NET 查找的环境中启动，并确认使用内置 CLR。
