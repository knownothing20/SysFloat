# SysFloat v1.0.3

## 透明质感修复

- 将全窗口透明改为仅背景按像素透明，保持文字、数字和指标颜色清晰。
- 背景加入轻微渐变与边缘高光，菜单明确标注背景不透明度。
- 不透明、75%、50% 三种模式保留原来的偏好值。

## 资源控制

- 不增加实时模糊、动画或后台轮询。
- 复用透明绘制缓冲区，按需更新；普通不透明模式保留现有绘制路径。
- 继续保留应用内存分组、省资源采样和隐藏时停止界面计时器。

## 验证

140 项检查通过，包括像素背景 alpha、前景颜色、实际分层窗口、模式/布局切换、点击交互、缓冲复用与隐藏/退出释放。连续模式切换的 GDI 对象数保持 27 → 27。

下载 `SysFloat.exe`，适用于 64 位 Windows，不需要安装 .NET；校验值见 `SysFloat.exe.sha256`。
