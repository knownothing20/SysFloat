# SysFloat v1.0.2

## 修复应用内存排行

- 将单进程总工作集改为按应用分组的私有工作集，更接近任务管理器“进程”页的内存口径。
- 汇总应用的后台和子进程，显示应用名称及进程数量。
- 使用真实进程身份和可执行文件信息分组，不为 Codex、Claude 或其他应用硬编码数据。
- 权限不足或计数器不可用时明确标注，避免把私有提交量、共享页或未知数据当成真实占用。

## 资源控制

- 仅展开版可见且选择内存排行时采集应用内存。
- 限制元数据缓存，复用采样结果，关闭进程/快照句柄。
- 保持省资源模式和按需排行采集；不增加后台联网服务。
- 图表复用绘制缓冲区；时钟按分钟唤醒，隐藏窗口后停止额外界面计时器。

## 验证

102 项检查通过，包括私有工作集与独立 Windows PDH 计数器的交叉验证、真实应用合计、同名不同路径隔离、PID 复用和句柄稳定性。开发机缓存采集平均约 15 毫秒/次；这是本机实测，不代表所有机器的固定开销。

Windows 的内部分组、挂起状态与刷新时刻可能导致细微差异，不保证与任务管理器每一刻逐字节相同。

下载 `SysFloat.exe`，适用于 64 位 Windows，不需要安装 .NET；校验值见 `SysFloat.exe.sha256`。
