# SysFloat v1.0.4

## 统一应用排行

- CPU、内存、显存统一按应用归组合计，并显示参与统计的进程数量。
- CPU 先计算全部可读取进程的使用率，归组后再取 Top 5，避免遗漏多进程软件的其他成员。
- 显存先汇总进程的专用显存，再按应用归组；不会用普通内存冒充显存。
- 不仅按进程名合并，避免不同软件启动的 `node`、`python`、`rustc` 被错误算在一起。无法可靠确认归属的进程保留独立条目。
- CPU 排行标明约 5 秒平均，避免与左侧不同采样时段的系统总量直接对照。

## 资源控制与边界

保持只有展开版可见时才采集选中的排行，约每 5 秒一次；不增加后台轮询、实时模糊或动画。

CPU 身份与累计时间由同一个原生进程句柄读取，避免重复打开进程以及 PID 复用时串接数据；CPU/显存归组不读取额外的私有工作集。显存只对有用量的成员做归组，保留完整父链用于识别归属。

CPU 排行不再按进程名隐藏 `dwm` 等可读取的系统进程，便于排查桌面合成等系统负载。

应用归组仍可能与任务管理器的内部分组存在差异；权限不足或成员退出时，不猜测缺失数据。显存计数器可能包含跨进程共享资源，不能把应用排行相加当成硬件传感器总量。

## 验证

169 项检查通过，覆盖全成员汇总后 Top 5、同名程序隔离、独立窗口边界、Shell 启动链、PID 复用/缺失、循环父链、真实 CPU/内存/显存排行，以及原有透明、DPI、提醒和交互回归。

本机短测身份采集缓存平均约 23.6 ms/次，连续采集进程句柄保持 593 → 593；该数字仅为当前机器与负载下的样本，不代表固定开销或长期性能保证。

下载 `SysFloat.exe`，适用于 64 位 Windows，无需安装 .NET；校验值见 `SysFloat.exe.sha256`。
